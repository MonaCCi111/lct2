Состояние насоса, версия pump_scada_v1

Сборка локальных артефактов:

python -m production_ml.pipeline.build_pump

Обучение и упаковка:

python -m production_ml.pipeline.train_pump
python -m production_ml.pipeline.package_pump

Инференс активного маршрута:

python -m production_ml.pipeline.score_active --model pump_scada_v1 --start 2025-01-01 --end 2026-07-01 --output production_ml/data/pump_v1/scores.parquet

Проверка:

python -m validation.check_pump

Порог 0,11 зафиксирован на июле–декабре 2024 до просмотра 2025–2026.
На периоде политики получено 146 заявок, 35 совпадений и покрытие 35 из
312 доступных эпизодов. На 2025–2026 без изменения порога получено 585
заявок и 127 совпадений с будущими эпизодами.

Цель – автоматическая тревога насоса SCADA через 1–48 часов. Статус
«Работают все насосы в АНС» учитывается как тревога, потому что так его
пометил источник. Модель не подтверждает подтопление, физический отказ
или необходимость ремонта.
