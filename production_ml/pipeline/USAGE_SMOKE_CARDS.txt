Исторические карточки сигналов дыма

python -m production_ml.pipeline.build_smoke_cards
python -m validation.check_smoke_cards
python -m validation.check_smoke_live_evidence

Вход – ранее собранная витрина smoke_evidence/signals.parquet. Выход –
smoke_evidence/cards.parquet, локальный файл вне Git. Сигналы группируются
по объекту и точному пикету при разрыве не более 15 минут. Если пикет
не найден, используется канал. Карточка хранит первое и последнее время,
число записей и каналов дыма, число каналов объекта за 15 минут и доступные
сравнения температуры за предшествующие окна 0–6 и 6–30 часов.

Это итоговая историческая карточка эпизода. В живом потоке её надо обновлять
по мере поступления сигналов; журнал не содержит времени доставки, поэтому
одинаковые временные метки могут приходить в неизвестном порядке.
Сопоставление пикетов сделано по названию канала. Пожары не размечены.
Карточки не переводятся автоматически в черновики нарядов.

Для нового однозначного сигнала используйте
production_ml.pipeline.smoke_live_evidence.build_signal_evidence.
Функция принимает текущий сигнал, однозначные дымовые сигналы за 15 минут
и числовые замеры температуры за 30 часов. Каждая строка содержит
channel_id, event_time, object_id и нормализованный piket; у температуры
дополнительно есть numeric_value. Текущий сигнал функция добавляет сама.
Выходные поля совпадают с одной строкой исторической витрины signals.parquet.
Сверка двух реальных событий 2024 и 2025 годов дала ноль расхождений.
При одинаковых временных метках расчёт использует только уже полученные
события; поздняя доставка может изменить историческую карточку.
