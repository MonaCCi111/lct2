Действующие диагностические модели

power_phase_scada_v2 – Состояние фазы.
pump_scada_v1 – Состояние насоса.

Расчёт баллов выполняется отдельно для каждого типа:

python -m production_ml.pipeline.score_active --model power_phase_scada_v2 --start 2025-01-01 --end 2025-02-01 --output production_ml/data/phase_scores.parquet
python -m production_ml.pipeline.score_active --model pump_scada_v1 --start 2025-01-01 --end 2025-02-01 --output production_ml/data/pump_scores.parquet

Общий поток заявок:

python -m production_ml.pipeline.create_combined_tickets --phase-scores production_ml/data/phase_scores.parquet --pump-scores production_ml/data/pump_scores.parquet --output production_ml/data/tickets.parquet

Каждая модель применяет свой заранее зафиксированный порог. После этого
кандидаты объединяются строго по времени, внутри одной временной метки –
по убыванию калиброванного балла. Общий лимит равен 10 заявкам в сутки,
пауза для одной пары модель/канал – 48 часов.

temperature_scada_v1 не участвует в активном расчёте.
