Температурная ветка, версия temperature_scada_v1

Статус: research_candidate. В активный инференс не включена, потому что
в периоде политики июля–декабря 2024 доступно только 11 уникальных
будущих эпизодов.

Сборка локальных артефактов:

python -m production_ml.pipeline.build_temperature

Обучение и упаковка:

python -m production_ml.pipeline.train_temperature
python -m production_ml.pipeline.package_temperature

Проверка:

python -m production_ml.pipeline.score_temperature --start 2024-07-03 --end 2024-12-30 --output production_ml/data/temperature_v1/policy_2024_scores.parquet
python -m validation.check_temperature

Модель поддерживает только тип «Датчик температуры». Цель – начало
автоматической тревоги SCADA через 1–48 часов. Это не подтверждённый
пожар, физический отказ или ремонт.

Порог 0,03 зафиксирован на периоде политики до просмотра 2025–2026.
При лимите 10 заявок в сутки и паузе 48 часов он дал 49 заявок и покрыл
3 из 11 доступных эпизодов. Эти числа недостаточны для активного статуса.

Числовые значения используются без объявления единицы измерения и без
автоматического удаления крайних значений. События, в которых одна
временная метка содержит одновременно тревожное и нормальное состояние,
не создают целевой эпизод.
