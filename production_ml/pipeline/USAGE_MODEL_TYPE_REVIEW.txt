Воспроизведение пункта 2 из корня ML-каталога

Профиль всех 19 типов и будущих целей неисправности:
 .\.venv\Scripts\python.exe -m production_ml.pipeline.research_type_targets
Локальный вывод: production_ml/data/type_targets.json. Содержит
годовые объёмы, тревожные статусы и канал-дни неисправности по
полугодиям. fault_totals считает уникальные канал-дни по всем выбранным
статусам вместе; их нельзя получать суммой отдельных статусов.
Профиль не решает автоматически, годится ли модель.

Исследование насоса без изменения активного пакета:
 .\.venv\Scripts\python.exe -m production_ml.pipeline.research_pump_variants
Вывод содержит четыре варианта, периоды train/cal/policy/diag и
отдельный исторический 2021 год. Пороги компактной модели заданы
квантилями калибровки; результаты 2025–2026 диагностические.

Исследование статусов неисправности ИБП, КД АВ и состояния охраны:
 .\.venv\Scripts\python.exe -m production_ml.pipeline.research_fault_candidates
Локальные полные результаты: production_ml/data/fault_candidate_results.jsonl.
Модели обучаются заново при каждом запуске, пакеты не выпускаются.
Пороговые уровни 0,90; 0,95; 0,98; 0,99; 0,995 берутся только из
калибровки. Очередь моделирует паузу 48 часов на канал без дневной
квоты. Статусы цели – буквально указанные значения SCADA, не ремонты.

Проверить полный перечень решений по справочнику и активному реестру:
 .\.venv\Scripts\python.exe -m validation.check_model_type_decisions

Источники: очищенные Parquet 2019–2026 и один текущий справочник.
Источник не содержит времени доставки, подтверждённых отказов и
исторических версий справочника. Файлы в production_ml/data/ локальны,
большие Parquet и MD не добавляются в Git.
